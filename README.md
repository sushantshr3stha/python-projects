## ▶️ How to Run

1. Clone the repository:
   ```
   git clone https://github.com/sushantshr3stha/python-projects.git
   cd python-projects
   ```
2. Run any project with Python 3:
   ```
   python calculator.py
   ```
   Replace `calculator.py` with the file you want to run.

`ollama1.py` needs [Ollama](https://ollama.com) installed with a model downloaded before it will work.
